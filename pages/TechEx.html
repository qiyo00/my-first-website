29/January/2026

SVG Experiment

Sleeping: No interaction.

Alert: Hover your mouse.

Active: Click and hold.

Ref: A flea from Hollow Knight: Silksong

Reflection

  1. Planning the Assets

    I started by drawing three versions of the flea in Adobe Illustrator: Sleeping, Hover, and Awake. The key lesson was keeping the viewBox and artboard size exactly the same for all three. This ensures that when the flea changes states, it doesn't "jump" or move out of place.

  2. Combining the Code

    Instead of using three separate image files, I combined them into one SVG. I put the code for each flea into its own group tag (<g>). By using CSS to change the opacity, I can hide two versions and only show the one I want.

  3. Fixing Style Bugs

    Illustrator often gives different parts of a drawing the same name, like .cls-1. When I put the files together, the colors got mixed up. I fixed this by:

    • Inlining styles: Putting the color data directly into each path.
    • Unique IDs: Giving each color gradient a specific name so they don't fight.
  4. Making it Move Naturally

    To make the flea look "alive," I used CSS animations. I used a small scale change (1.03 height) and set the transform-origin to the bottom (50% 100%). This keeps the flea's feet on the ground while its body moves.
